# First-release issues (draft)

These are drafts to be created as GitHub Issues labelled `needs-triage` once Claude has GitHub write access. Delete this file after they are created. See [design.md](design.md) for the full design.

1. **Pipeline: select eligible wildcat wells.** Set up `pipeline/` (Python and pandas) to download FactPages wellbore data and keep wells that are WILDCAT, main wellbore only, and have a known result. Map each result to Discovery or Dry (shows count as Dry). Frontier wells are included. Tests for the filters and the mapping.
2. **Pipeline: build pre-spud Dossiers (ADR 0001).** For each Prospect, build the free Dossier: position and block, water depth, target, decade. Hide the well's name, the real operator ("Operator A") and the exact year. Add tests that fail if any Dossier field is dated on or after the spud date, or contains the well's name, discovery name or year. *Blocked by 1.*
3. **Pipeline: Hint content and value-of-information prices.** Build four Hints, each using only data from before the spud date: Licence history, Regional analogues ("no analogues: frontier acreage" for frontier wells), Seismic coverage, and Nearest discovery. Price each kind of Hint by how much it improves prediction of the Outcome, scaled so the most useful one costs about 0.2 × Well Cost. The underlying numbers are never shown to the player. *Blocked by 2.*
4. **Pipeline: LLM plain-language summaries with leak check.** Give the LLM only fields from before the spud date. Reject any summary containing names or years that would reveal the outcome. A human spot-checks a sample. Write the versioned `prospects.json`, the only interface between the pipeline and the app. *Blocked by 2.*
5. **App: scaffold.** Set up an installable mobile-first web app with TypeScript, React and Vite. Interface text lives in translation files (English). Show the Sodir NLOD credit. Load `prospects.json` as a static file.
6. **App: Campaign loop.** 10 random Prospects and a budget of 5 × Well Cost. The Confidence slider starts at 50%, and Drill or Drop stay locked until it has been touched. Score +3 × Well Cost for a Discovery and −1 × Well Cost for a Dry well. Show a Reveal for every decision, including what a Drill would have earned or lost after a Drop. The Campaign ends after 10 Prospects or when the budget can't pay for another Drill. *Blocked by 5.*
7. **App: Hints, Geologist View, map.** Buy Hints from the shared budget. The Geologist View is free. Add a MapLibre map with Sodir's block outlines. *Blocked by 6 and 3.*
8. **Backend: Supabase in an EU region, Decision Records (ADR 0002).** Anonymous sign-in. A Decision Record schema holding: Dossier version, Hints bought, sections opened, time taken, Confidence, the decision and the Outcome. Queue records on the device and sync them so play works offline. *Blocked by 6.*
9. **App: Training Consent and Player Profile.** A separate, explicit opt-in that explains in plain language what is collected and that it trains an AI model. After the first Campaign, ask for the Player Profile on two skippable screens. Disciplines: geologist, geophysicist, reservoir engineer, production engineer, other industry, not in the industry. Experience: student, 0–5, 5–15, 15+, not applicable. *Blocked by 8.*
